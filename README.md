# 家具ピタ

住宅図面のPDF上で家具の配置を実寸で試せるWebアプリです。Next.js 16 / App Router / TypeScript / React 19 / PDF.js / IndexedDB（idb）を使用します。ログイン不要です。

## 開発・起動

miseでBun 1.3.14をインストールしてください。

```sh
mise install
mise exec -- bun install
mise exec -- bun --bun run dev
```

http://localhost:3000 を開きます。インストール時にPDF.jsのworker・日本語CMap・標準フォント・WASMをpublicにコピーします。開発・ビルド・スクリプト実行にはmise管理のBunを使用します。

```sh
mise exec -- bun --bun run test
mise exec -- bun --bun run typecheck
mise exec -- bun --bun run build
mise exec -- bun --bun run start
```

主要操作の自動ブラウザ検証は、別ターミナルで `mise exec -- bun --bun run dev` を起動し、`mise exec -- bunx --bun playwright install chromium` の後に `mise exec -- bun scripts/check-browser.mjs` を実行してください。PDF読み込み、校正とエラー、四角形・円形、寸法変更、回転、削除、ズーム、パン、移動、画面サイズ変更、再読み込み復元、ページ切替を確認します。座標変換の単体テスト、本番ビルド、TypeScriptチェックも確認済みです。

## 使い方

1. 「PDFを読み込む」から住宅図面を選び、表示ページを選択します。
2. 校正点1・2の「図面で指定」を押し、できるだけ離れた点をクリックします。それぞれの既知の実寸X・Yをmmで入力します。右向きX、下向きYの座標を推奨します。例えば横方向に5000mm離れた点なら `(0, 0)` と `(5000, 0)` です。
3. 「この2点で校正する」を押します。同一図面位置・同一実寸座標・無効な入力はエラーになります。位置・座標の変更後は再校正してください。
4. 「四角形」「円形」を選び、図面上をクリック・タップすると既定サイズで配置します（四角形は幅900×奥行き600mm、円形は直径600mm）。ドラッグすると描いた大きさを実寸換算して初期寸法にします。円はドラッグ領域の長辺を直径とします。配置後は自動で通常操作へ戻ります。同じ追加ボタンをもう一度押すかEscで追加モードを終了できます。追加モードでは家具のない場所でもパンせず配置操作を優先します。
5. 家具を選択し、名前・色・実寸の中心位置・寸法・角度を編集します。ドラッグで移動、上部の丸いハンドルで回転、右パネルで削除できます。角度は実寸X軸からY軸方向への角度です。
   選択した家具はDeleteキーでも削除できます。家具名・寸法などの入力欄を操作している間は、文字の編集を優先し家具は削除しません。家具のない図面上をクリック・タップすると選択解除します。余白をドラッグした場合はパンになり、選択は維持します。
   選択すると四隅に丸いサイズ変更ハンドルを表示します。マウス・タッチで丸をドラッグすると反対側の角を固定して拡大縮小し、寸法と中心座標をmmで更新・保存します。マウスでは未選択の家具でも四隅へカーソルを移動して操作できます。回転した家具にも対応し、円形は真円のまま直径を変更します。寸法は最小1mmで反転を防ぎます。ハンドルはズームにかかわらず画面上で同じ大きさです。
6. ホイールまたは＋・−でズーム。家具上をドラッグすると家具を選択・移動し、家具のない図面上をドラッグするとパンします。家具が選択済みでも余白ではパンになり、選択と実寸座標は維持します。「選択」「パン」の切替ボタンはありません。「全体」で図面全体を表示します。
   タッチパネルでは図面上の2本指のピンチイン・ピンチアウトで図面だけを拡大縮小できます。2本指の中心を基準に、＋・−と同じ10〜600%の範囲でズームします。2本指操作中は家具の移動・描画を中断し、指をすべて離してから1本指操作に戻ります。アプリ内のブラウザ標準タッチズームを抑止し、設定パネルでは通常のスクロールを維持します。図面上のCtrl＋ホイール（タッチパッドのピンチを含む）もブラウザズームを抑止して図面ズームに変換します。
7. 変更は500ms後にIndexedDBに自動保存します。「保存済み」の表示を確認してからタブを閉じてください。再読み込みで最後の配置案が復元され、左上の選択欄で別の配置案を開けます。新しいPDFは新しい配置案になります。名前を変更できます。

### 図面を広く使う

- 左側の「図面・ページ設定」「実寸を合わせる」は見出しを押すと折りたためます。
- 図面上部の「＜」で左パネルを閉じ、「＞」で再表示します。ヘッダは48pxのコンパクトな表示です。
- PDF読込・変更は左パネルの「図面・ページ設定」にあります。四角形・円形の追加は図面上部のツールバーにあります。PDF変更で選んだファイルは新しい配置案になります。
- 「全画面」でアプリのヘッダと左パネルを隠し、図面と右の家具編集領域をブラウザの表示領域いっぱいに表示します。「全画面終了」またはEscで戻ります。ブラウザ自体のタブ・アドレスバーはそのままです。
- パネル開閉・全画面切替は家具の実寸座標・寸法や校正に影響しません。全画面でも保存状態を図面下部で確認できます。
- PDFの余白が多い場合は、左パネルの表示ページの下にある「範囲指定」を押し、使用する図面部分をドラッグで囲んでください。指定直後と「全体」を押したときは、その範囲が画面に収まるように表示します。未校正でも指定でき、タッチ操作にも対応します。
- 使用範囲はPDFページの固定座標でページごとに保存します。再読み込み・ページ切替時も復元し、家具や校正の座標を変更しません。範囲外は薄く表示しますが、PDFデータ自体は切り取りません。「範囲指定」で再指定、「範囲解除」でページ全体へ戻せます。小さすぎる範囲はエラーになります。

校正を行うと、左パネルにPowerPointのスライド一覧のようなページ一覧を表示します。指定範囲のPDFだけをサムネイルに描画し、家具は含めません。未指定ページはページ全体を表示します。ページを押すと切り替わり、従来のページ選択・校正入力も折りたたみ内に残っています。サムネイルは画面付近にあるページから描画します。

右パネルは家具名・色・寸法・中心位置・回転角度の順です。寸法を位置より先に編集できます。

### 家具の色を選ぶ

家具を選択すると、右パネルに現在の色が表示されます。色の行を押すと標準16色のパレットが開き、もう一度押すと閉じます。「自由に色を指定」では従来のカラーピッカーで任意の色も選べます。

「写真から色を取り込む」を開き、「撮影」（スマホの背面カメラを優先）または「画像を選択」（PC・スマホの画像ファイル）で画像を読み込みます。写真内の家具の部分をタップ・クリックすると、その位置付近の色を家具に反映します。画像で多く使われる色も最大6色の候補として表示します。背景の色も候補に含まれるため、家具の部分を直接選ぶ方法が確実です。

画像はブラウザのメモリ内で処理し、保存・送信しません。家具には選んだ色のみ保存します。画像を閉じる、別の家具を選ぶ、ページを再読み込みすると画像は破棄されます。カメラ起動は端末・ブラウザに依存し、PCではファイル選択になる場合があります。JPEG・PNG・WebPなどブラウザが表示できる形式に対応し、HEIC等はブラウザによって読み込めません。照明・影・撮影条件で色が変わるため、厳密な測色ではありません。

### iPad・日本語IMEでの数値入力

校正の実寸座標、家具の幅・奥行き・直径・中心位置・角度は、フォーカス時に入力済みの内容を全選択します。数値キーボードを指定したテキスト入力を使い、Backspaceで空欄にしてから再入力することもできます。日本語IMEの変換中は編集中の文字列をブラウザに保持し、確定後に数値へ反映します。全角数字・小数点・マイナス記号にも対応します。

家具の寸法を編集中に空欄・無効な値にしても、図形には最後の有効な寸法を保持します。そのまま入力欄から離れると有効な値へ戻します。校正座標の空欄は未入力として扱い、校正時にエラーにします。Chromiumのタッチ・IMEイベントで検証しており、iPad実機の日本語ソフトウェアキーボードは未検証です。

## 座標・保存設計

PDF.jsのscale=1のページ座標（左上原点、ページの既定回転適用後）で校正点を保存します。画面上の座標は `(ページ座標 × zoom) + pan`。家具の中心と寸法はmmで保存し、画面上の倍率やウィンドウサイズは保存値を変更しません。

PDFの2点をp1,p2、実寸の2点をr1,r2とすると、差分から `r = r1 + [[a,-b],[b,a]](p-p1)` を求めます。均一縮尺 `sqrt(a²+b²)`、回転、平行移動を含みます。家具表示には逆変換を使用します。初期描画の家具は図面の辺に揃う回転角を持ちます。校正変更時も家具の実寸値は保持し、新しい変換で表示します。

PDF本体（ArrayBuffer）、選択ページ、ページ別校正点・校正状態・家具、配置案名をIndexedDBに保存します。保存は直列化し、古い保存が新しい保存を上書きしないようにしています。PDFの転送で保存用バッファが切り離されないよう、PDF.jsにはコピーを渡します。

## デプロイとデータ保護

デプロイでIndexedDBを初期化・削除しません。同じオリジン（https/http・ホスト名・ポート）と同じブラウザプロファイルなら、PDF・校正点と実寸座標・家具・指定範囲・配置案を復元します。デプロイごとに変わるプレビューURL、localhostと本番、wwwの有無は別の保存領域です。本番では固定URLを使ってください。PDFを再読込すると新しい配置案になるため、既存の編集には左上の配置案選択を使います。

保存時にブラウザの永続保存を要求します（許可はブラウザ依存）。左パネルの「データの保護・バックアップ」で状態の確認・再要求もできます。これは容量不足による自動削除を抑える仕組みで、ユーザーによるサイトデータ削除や端末故障からの保護ではありません。

「配置案をバックアップ」は現在の配置案のPDF本体・全ページの校正・家具・使用範囲を `.kagupita.json` ファイルに保存します。URLやブラウザを変更する前にダウンロードし、移動先で「バックアップから復元」を使ってください。復元は新しい配置案を作り、既存データを上書きしません。全配置案を保護する場合は配置案ごとにバックアップしてください。クラウド保存・自動同期はありません。既に削除されたデータをバックアップなしで復元することはできません。

## iPadのホーム画面・ファビコン

間取りとソファを組み合わせた深緑のアイコンを設定しています。ブラウザ用のICO（16/32/48px）とPNG、iPad/iPhone用Apple touch icon（152/167/180px）、Webアプリのmanifest用アイコン（192/512px）を用意しています。

デプロイ後、iPadのSafariで本番URLを開き、「共有」→「ホーム画面に追加」で登録してください。アプリ名は「家具ピタ」です。既存のホーム画面アイコンには端末側で古い画像が残る場合があります。追加し直す前には配置案のバックアップを保存してください。アイコン・manifestの設定はオフライン動作の実装ではありません。iPad実機でのホーム画面追加は未検証です。

生成元とプロンプトは `public/icons/README.md` を参照してください。

## その他の制約

- 2点校正は相似変換です。縦横の倍率が異なる変形、せん断、写真の遠近歪み、鏡映は補正できません。
- 校正と家具はページ別です。未校正のページでは家具を追加できません。
- 暗号化・パスワード付きPDFは対象外です。大きなPDFはブラウザのメモリと保存容量に依存します。容量不足・保存不可は画面に表示します。PDF本体を含む保存を行うため、極端に大きいPDFの頻繁な編集は負荷が増えます。
- ローカル保存は同じブラウザ・同じオリジン内です。閲覧データの削除やプライベートモードの終了で消失する場合があります。クラウド同期、配置案削除、家具の衝突判定、Undo/Redoは未実装です。
- ズームとパンは表示専用で、再読み込み・ページ切替時は初期表示に戻ります。家具・校正・選択ページは復元されます。
- デスクトップの最新Chrome / Edgeを主な対象にしています。狭い画面では設定パネルが図面の下に並びます。日本語WebフォントはGoogle Fontsを参照し、未接続時はシステムフォントを使用します。
